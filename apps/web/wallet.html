2. Register

Registration publishes your viewing key on-chain and is required before any private action. There is no free-standing register call in the wallet API — it only happens bundled into a real deposit, so this step submits a small deposit purely to trigger it.

Checking registration status…

3. Shield (deposit into the pool)

A shield is two on-chain steps — ERC-20 approve then deposit — so the wallet may prompt twice. If this fails with NOT_REGISTERED, register first using the step above.

Transaction log
