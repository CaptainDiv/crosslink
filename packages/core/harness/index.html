Crosslink — Phase 0 derivation harness

Connect a wallet, sign the fixed derivation message, and read off the derived Starknet address. Entirely client-side: no network calls, no localStorage, no persistence. Only a SHA-256 fingerprint of the signature is ever displayed — never the raw signature.

Comparison

Connect and sign with both wallets to compare.
Before comparing across wallets: Phantom defaults to the derivation path m/44'/501'/0'/0', Solflare to m/44'/501'/0'. The same seed phrase lands on a different Solana account by default in each wallet. A valid cross-wallet test requires pointing both wallets at the same Solana account (check each wallet's account selector).
